## 004. 早押しの「押す」を、色ではなく形と厚みで早押しボタンにする

- 日付: 2026-08-27
- 対象: `src/styles.css`（`.buzz-button`）、`src/StudyView.tsx`

### 背景

早押しモードの「押す」が、他の主ボタンと同じ**全幅 358×48px の帯**で、早押しボタンに見えなかった。
実装前に方向を3案出して選んでもらった。

制約として、外部リソースは CSP（`img-src` を含む）で禁じているため、画像は使えない。CSS だけで描く。

### 決定

**直径 120px の円形**にし、放射グラデーション＋側面の厚み（`0 6px 0`）＋落ち影＋内側のハイライトで盛り上げる。
押すと `translateY(5px)` で沈み、**側面の厚みが 6px → 1px に縮む**。

色は**赤**（2026-08-27 ユーザー指定で、初版のティールから変更）。既存の赤とは役割が違うので
`--color-buzz` / `--color-buzz-light` / `--color-buzz-dark` / `--color-buzz-edge` を新設し、
`--color-again`（不正解）や `--color-danger` とは混ぜない。

**ボタンの中に文字は置かない**（同指定）。実物の早押しボタンと同じく色と形だけで示す。
読み上げのために `aria-label="押す"` は残す。

`primary` と `reveal-button` のクラスは**付けない**。`button.primary` の詳細度が `.buzz-button` より高く背景を、
`.reveal-button` が `width: 100%` を上書きしてしまうため。

### 比較した代替案

- ~~却下~~ → **採用（2026-08-27 変更）: 赤**。当初は「赤系が『不正解・危険』に割り当て済みで意味が衝突する」
  として却下したが、ユーザー指定で採用。**専用トークンを新設して既存の赤と分ける**ことで衝突を避けた。
  台座は敷いていない（側面の厚みだけで足りたため）
- 却下: **全幅の帯のまま質感だけ立体にする** — レイアウトが変わらずカード表示域を 611px のまま保てるが、
  「早押しボタンらしさ」という当初の目的をほぼ満たさない
- 却下: **押した瞬間に波紋を広げる** — 確認感は強くなるが、アプリ全体の静かなトンマナから浮く（ユーザー判断）
- 却下: **効果音（Web Audio）** — ファイル不要で鳴らせるが、本体のサイレントスイッチで消えるため当てにできない
- 却下: **振動（`navigator.vibrate`）** — **iOS Safari が非対応**なので、主な利用環境で効かない
- 採用: 円形・ティール・沈み込みのみ

### 影響範囲

- **カード表示域が 611px → 539px に縮む**（フッターが 96px → 168px）。早押しは文字が伸びるので、
  長い問題文でスクロールが増える。許容すると決めた（実機で「窮屈さは感じない」と確認済み）
- **状態が変わっても高さが動かないよう `.buzzer-slot`（`min-height: 128px`）で中身をくるむ。**
  最初はフッターへ `min-height` を置いたが、`padding-bottom` に `env(safe-area-inset-bottom)` が入る
  実機では「押す」の状態がその値を超え、押した瞬間にセーフエリアぶんだけ縮んで**問題文の位置が下がった**。
  デスクトップ検証では `env()` が 0 なので出ない。中身の側を固定する形なら余白がいくつでも揃う
- 押下表現は `main.tsx` の `data-pressed` 機構に乗る（iOS で `:active` が来ないため。`docs/decisions/003`）
- 汎用の押下表現（`scale(0.96)` ＋ `opacity: 0.72`）はこのボタンには不要なので、`.buzz-button` 側で打ち消す
- `data-motion="crossfade"` では沈ませないが、**影の縮小は残す**（沈まないうえ影も動かないと手応えが消える）

### 検証

preview + Playwright 390×844。

- 120×120px、`border-radius: 999px`、フッター内で中央（左右の中心が画面中心と一致）
- 押下中 `matrix(1, 0, 0, 1, 0, 5)`、側面 `0 6px 0` → `0 1px 0`、`opacity` は 1 のまま（汎用の減光を打ち消せている）
- 離すと元へ戻る
- `data-motion="crossfade"` では `transform: none` のまま、側面は 6px → 1px に縮む
- 合成 `PointerEvent`（`:active` が立たない＝ iOS の代役）でも沈む
- 実クリックで押下が機能する（`7/7 文字で押した`、フッターが「答えを表示」に切り替わる）
- **セーフエリア相当（`padding-bottom: 46px`）を CSSOM で注入した状態で、フッター 210px・カード 497px・
  問題文の上端 344px が「押す前」と「押した後」で完全に一致**（`<style>` 注入は CSP で弾かれるので CSSOM で当てる）
- コンポーネントテスト10件（`tests/study-view.test.tsx`）でも状態遷移を固定

**判断が間違いだったとわかる条件**: 長い問題文でカード内スクロールが常態化する、または 120px が片手で押しにくい。
