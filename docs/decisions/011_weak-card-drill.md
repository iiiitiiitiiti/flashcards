## 011. 苦手カードは進捗だけで判定し、開始シートの「範囲」から期限前でも出す

- 日付: 2026-09-04
- 対象: `src/srs.ts`（`isWeakCard`・`buildStudyQueue` の `focus` / `weakSince`）、`src/types.ts`（`StudyFocus`）、`src/App.tsx`（開始シート「範囲」）、
  `src/StudyView.tsx`・`src/StudyResult.tsx`（文言の分岐）、`src/styles.css`（開始シートのスクロール）

### 背景

「もう一度」が多い・定着していないカードだけを集めて回したい（2026-09-04 ユーザー要望）。
FSRS の通常キューは期限が来たカードしか出さないので、苦手なカードほど次の出番が遠く、まとめて復習する手段が無かった。

### 決定

1. **判定は進捗（ProgressDTO）だけ**で行い、評価ログは読まない。次のどれかで苦手とする
   - 3回以上出してもまだ定着していない（`reps ≥ 3 && state !== Review`）
   - 間隔が 21 日未満のうちに、忘れたことがある（`scheduledDays < 21 && lapses ≥ 1`）
   - 間隔が 21 日未満のうちに、難しさが 8 以上（`scheduledDays < 21 && difficulty ≥ 8`）
2. 並びは忘れた回数 → 難しさの降順（ランダム指定ならシャッフル）。**期限前でも出す**。新規（進捗なし）は含めない
3. 入口は学習開始シートの「範囲: すべて／苦手だけ」。枚数・タグ・モードは既存のものがそのまま効く。範囲は**覚えない**（毎回「すべて」で開く）
4. **ドリルを開いた時刻（`weakSince`）以降に評価したカードは出さない。** 「つづける」はこの時刻を引き継ぐ。
   苦手は1回「わかった」でも苦手のままなので、除かないと「つづける」が同じカードを際限なく出す。開き直せば同じカードをもう一度ドリルできる
5. 早期復習の影響は許容する。FSRS は評価のたびに今日起点で次回を計算するので、期限まで3か月あるカードを今日ドリルすると次回は今日から数え直しになる。シートの説明文にその旨を書く

### 判定の根拠（ts-fsrs 5.4.1 の実測、2026-09-04）

- `lapses` は **Review 状態で「もう一度」を押したときだけ**増え、減ることはない。学習中に何度「もう一度」を押しても 0 のまま（again×3 → Learning・reps 3・lapses 0）。
  だから「学習中で躓いている」は reps と state で、「定着後に忘れた」は lapses で見る
- `difficulty` は初回「もう一度」で 6.4、2回で 8.8。Review のまま「難しい」を押し続けるカードは lapses が増えないので、difficulty で拾う
- 既定の学習ステップは2つ。good→good で Review に届く（reps 2）。3回出しても届いていなければ躓いている
- 21 日は Anki の mature の閾値。lapses は永久に残るので、間隔で切らないと「一度でもつまずいた全カード」が苦手になる

### 比較した代替案

- 却下: 評価ログで判定（直近30日の「もう一度」2回以上） — 学習開始のたびに最大2万件を読む。ユーザーが進捗判定を選択
- 却下: 判定を `lapses ≥ 1 || (reps ≥ 3 && 未定着)` だけにする（v1 案） — Opus レビューで2つ穴が出た。Review のまま「難しい」連打は lapses が増えず取りこぼす。
  lapses は減らないので、半年前の1回のミスで永久に苦手扱いが残る。difficulty と scheduledDays を足した
- 却下: 「今日評価したカードを除く」（v1 案） — 朝間違えたカードを夜やり直せない。結果画面は描画ごとに「今日」を判定するので、日付を跨ぐと3分前に評価したカードが復活する
- 却下: ホームのデッキカードに「苦手 N」ボタン — 起動時に全デッキの進捗を読む。シートの切替で足りる（ユーザー選択）
- 却下: 範囲を前回の選択として覚える — 前回「苦手だけ」のまま別のデッキを開くと「0 枚・開始不可」のシートが出る。タグのようにデッキごとに覚える価値も薄い
- 却下: ドリル中は進捗を書かない（表示だけ） — 早期復習の間隔リセットは避けられるが、定着率・評価ログ・統計を別扱いにする設計が要る
- 採用: 上記の決定

### 影響範囲

- 開始シートが5段になったので `.sheet-backdrop .sheet` にも max-height / overflow を当てた（低い画面でシート内スクロール）
- 結果画面の定着率ゲージとコメントはデッキ全体の値のまま。苦手ドリル直後に「ほぼ完成です」が出ることはありうる
- `buildStudyQueue` の引数が2つ増えた（`focus`・`weakSince`。省略で従来どおり）

### 検証

- `tests/srs.test.ts`（9 件）。境界: reps 2/3、scheduledDays 20/21、difficulty 7.9/8。実遷移: `rate()` を回して「学習中の again では lapses が増えないが苦手になる」「順調に定着 → 1回忘れると苦手」。
  キュー: 並び順・期限前・新規除外／`weakSince` の除外と null／タグ／`focus` 省略で従来どおり
- `tests/study-view.test.tsx`（3 件）: 苦手だけが忘れた回数順に出て全部評価すると「つづける」が出ない、枚数より多ければ「つづける」が親へ再開を伝える、苦手0枚の文言
- preview + Chrome: 開始シートに「範囲」が出て、「苦手だけ」で枚数と説明文が切り替わり、0 枚なら開始が無効になる
- 兆候: 苦手が多すぎてドリルが終わらない（閾値 21 日 / difficulty 8 の見直し）、逆にほとんど 0 枚（reps ≥ 3 の条件が厳しすぎる）
