## 015. 統計の「タグ別」は ★ と「出題済み」を既定にし、展開で全タグを出す

- 日付: 2026-09-04
- 対象: `src/stats.ts`（`summarizeTags`・`isCommonTag`）、`src/StatsView.tsx`（タグ別の節）、`src/styles.css`（`.link-button`）

### 背景

013 で統計タブを拡充したとき、タグ別の内訳はユーザーが対象から外した。その後「タグ別も」と依頼があり（2026-09-04）、013 の決定を覆して足す。
タグは 185 種・29,867 枚。★☆☆ 6,984 枚と「出題済み」801 枚が全デッキにまたがり、残りはデッキ固有の小ジャンル（医学 682、食-料理･調理 667 など）。
★★☆・★★★は数枚しか無く、枚数順に並べると 185 行の下へ沈む。

### 決定

1. **集計はデッキ別と同じ列**（枚数・定着率・復習・苦手）。複数タグのカードはそれぞれのタグに数える。分母はそのタグの付いた出題対象の枚数。
   1 枚に同じタグが 2 回付いていても 1 回、空文字のタグは無視する（JSON 直編集・インポート経由で入りうる）
2. **並びはデッキ別と同じ「復習 → 苦手 → 枚数 → 名前」。** 見た目が同じ表なので規則も揃える
3. **既定は共通タグ（★ と「出題済み」）だけ。** 判定は `isCommonTag`（`isDifficultyTag` か `SHUTSUDAI_TAG`）で、データの分布に頼らない。
   見出し横の「すべてのタグを表示（N 種）」で全タグに広げ、「★と出題済みだけにする」で戻す。状態は覚えない
4. 共通タグが 1 つも無い、または全部が共通タグのときは、絞る意味が無いので最初から全タグを出してボタンを出さない
5. 切替ボタンは表の**上**（見出しの右）に置く。185 行の下に置くと、折りたたんだ瞬間にボタンが画面外へ飛ぶ。`aria-expanded` / `aria-controls` を付ける
6. 注記に「タグ別は複数のタグを持つカードをそれぞれに数えるので、行の合計は総枚数と一致しない」を足す。7,263 枚が ★ と小ジャンルの両方に載る

### 比較した代替案

- 却下: 既定を「2 デッキ以上に付くタグ」にする（v1 案） — 1 デッキだけの環境で 0 になり、逆にデッキを分割し直すと小ジャンルが全部 2 デッキにまたがって 185 行が既定になる。
  片方のデッキで非表示にすると行が予告なく消える。Opus レビューの指摘で、意味で決める `isCommonTag` へ
- 却下: 既定を上位 N 件（枚数順） — ★★★（7 枚）は入らない。タグ別の主目的は難易度ごとの定着率を見ること
- 却下: 全タグを枚数順に並べるだけ — ★★★が沈む
- 却下: ★ など難易度タグだけに限る — 小ジャンルごとの弱点（「医学は弱い」）も見たい場面がある。展開で見られる形にした
- 却下: 「タグなし」行 — ホームのタグ絞り込みに無い概念を統計だけに作らない
- 却下: `deckCount`（何デッキに付くか）を型に持つ（v1 案） — 既定の判定にしか使わず、表にも出さない。013 の `memorized` と同じ基準で落とした
- 採用: 上記の決定

### 影響範囲

- 統計タブの節の並び: … → デッキ別 → **タグ別** → 全期間 → 注記
- `.deck-table` をそのまま使う。追加は `.link-button`（見出し横の文字だけのボタン）
- 集計コスト: 実データ 29,867 枚・185 タグで `summarizeTags` は 24.5ms（Node・デスクトップ。`summarizeDecks` は 4.1ms）。iPhone なら数倍でも 100ms 未満の見込み。
  185 行の展開は Chrome で 93ms。表の高さは 9,840px（幅 485px）。390px ではタグ名が折り返す行が増えるので 1 万数千 px になる

### 検証

- `tests/stats.test.ts`（+6 件、全 304 件）。集計: 複数タグを各タグに数える／定着率がタグ付きカードだけの `retentionPercent` と同値／並び／同じ id が別デッキにあっても取り違えない。
  整合: 復習が「まとめて学習」でそのタグを選んだときの枚数（`buildStudyItems`）と一致。
  入力の揺れ: 重複タグ・空文字／非表示だけのタグは行に出ない／`isCommonTag`
- preview + Chrome（17 デッキ・677 進捗の fixture）。既定 4 行（★☆☆ 6,984 枚・出題済み 801・★★★ 7・★★☆ 5）。
  「すべてのタグを表示（185 種）」で 185 行になり、ボタンは「★と出題済みだけにする」に変わって `aria-expanded` が切り替わる。横スクロールなし。注記に 2 文追加
- iPhone 実機での 185 行展開は未測定（Mac 引き継ぎに記載）
- 兆候: 展開した 185 行が長すぎて戻りにくい声（ページ送りや検索欄の追加）、小ジャンルの定着率をホームからも見たい声（デッキ詳細のタグ絞り込みに数字を出す）
