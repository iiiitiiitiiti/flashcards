# Design Decisions

UI に関する確定済みの設計判断。変更するときはここを更新する。

## ビジュアル言語（2026-08-10、Newmonic https://newmonic.baton8.com を参考に採用）

- ティール基調 + 温かみのあるオフホワイト背景（#f6f6f4）。プライマリは #2e7382（Newmonic の #489FB2 は白文字とのコントラスト 3.05 で不採用。当プロジェクトの 4.5:1 基準を満たす濃ティールに調整）
- **Q/A の色分け**: 一覧・学習画面とも「Q」=ティール、「A」=赤（#c53f35、ダークは #ef8b80）。答えは常に赤文字
- デッキ詳細の各カードに元順の番号とフェーズバッジ（= FSRS reps。定着（state=Review）は塗りつぶし）
- ホームのデッキカードに定着率ドーナツゲージ（定着カード数 / 全カード数、conic-gradient 製）
- セクション見出しはティール縦棒 + 太字。アプリタイトルはティール + letter-spacing 0.08em
- ボタン角丸 8px（Newmonic の角丸小さめの印象を反映しつつタップターゲット 44px は維持）
- 評価4択 + 間隔表示は維持（Newmonic は2択だが、SRS の判断材料として4択を優先する既決定）

- 学習画面の主要操作（答えを表示・4評価）は画面下部固定（HIG: Reachability。片手操作の親指ゾーンに置く）。カード本文は中央寄せ・24px/22px でコンテンツ優先（Deference）
- 評価ボタンには ts-fsrs の `repeat()` による次回間隔の目安（分/時間/日/か月/年）を常時表示する（評価の判断材料。Anki 互換の慣習）
- セッション進捗はヘッダー直下の進捗バーで表示。「もう一度」の再出題でバーが一時的に戻るのは仕様（正直な残量表示を優先）
- カラーは CSS 変数トークンで一元管理し、`prefers-color-scheme: dark` に対応。theme-color メタタグも light/dark の2枚で切替
- 全テキストはコントラスト比 4.5:1 以上を維持する（WCAG SC 1.4.3）。「難しい」ボタンは #b07a1f → #8a5f14 に変更済み（3.72→5.6）。値を変えるときは scratchpad の ui-audit スクリプト相当で実測してから
- ボタンは最小 44px 高（HIG タップターゲット）。学習画面の主要ボタンは 56px
- バッジ・タグはチップ表示（復習=赤系 / 新規=青系 / 完了=緑系。色+テキストの併用で色覚に依存しない）
- 状態切替（カードめくり）は state 即時反映、CSS transition は装飾のみ。`transitionend` にロジックを載せない（iOS「視差効果を減らす」対策）。`prefers-reduced-motion` では進捗バーの transition を無効化

## 学習画面の操作（2026-08-10 ユーザー指定）

- 学習中はページの上下スクロールを禁止する（body に study-lock クラス、overscroll-behavior: none）。カード本文が収まらない場合のみカード内部でスクロール
- カード枠は操作エリアを除く画面の縦いっぱいに広げる。中央寄せは auto マージン方式（justify-content: center は overflow 時に先頭が切れるため使わない）
- カードのタップは表⇄裏のトグル（答えを開いた後もタップで問題面に戻れる）
- カードの表裏は 3D 反転アニメーション（rotateY・0.4s）、次カードは右からの入場アニメーション（0.28s、key 再マウントで発火）。両面を常に DOM に置き backface-visibility で切替、非表示面は aria-hidden。状態切替は即時で、アニメはロジックに関与しない。**OS の `prefers-reduced-motion` は参照しない**（2026-08-10 ユーザー決定。Newmonic 等の一般アプリと同じく既定でフル再生）。動きを減らすのはアプリ内設定（設定画面 → アニメーション、`data-motion="crossfade"`）で、回転・移動をクロスフェードへ置き換える。zoo-aquarium-log の「既定は表示・設定でオフ」と同じ方針
